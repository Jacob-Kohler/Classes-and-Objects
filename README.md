# Classes-and-Objects
This project is a basic introduction on classes and objects. A class is created for a soccer club containing information about the club such as name, goals scored, goals conceded, and the league. It also calculates the goal difference for the club. Another class is created for a football team, this has team name, wins, losses, and stadium name. It also displays the team record. When SportsApp is run it is expected to output all of the information about the teams as well as be able to edit the information and display the updated information.
